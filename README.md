# alessionovel.github.io

Personal website of Alessio Novel.

## Publish on GitHub Pages

1. On GitHub create a new **public** repository named exactly `alessionovel.github.io`.
2. Upload `index.html` and `Alessio_Novel_CV.pdf` (and `photo.jpg`, if you add one) to the root of the repo.
3. Go to **Settings → Pages**, set *Source* to "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at https://alessionovel.github.io

## Updating

- **CV**: replace `Alessio_Novel_CV.pdf` with the new export (same file name).
- **Photo**: replace `photo.jpg` with a new square image (same file name).
- **Colors**: all colors are variables at the top of the `<style>` block (`--accent` is the main purple).
